# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, through [a GitHub security advisory](https://github.com/punchframework/punch/security/advisories/new). Do not open a public issue.

Include what is affected, the Punch version or commit, and the steps to reproduce it. Reports are answered on a best-effort basis by a small team.

## Supported versions

Punch is at version 0.1 and has not yet had an independent security review. Fixes go into the latest version only.

## Verifying a release

Each release lists its archives in `SHA256SUMS` and carries a build provenance attestation. [Installing Punch](docs/guides/installing.md) shows how to check both.
